 ## Description 🔎
 This is Minecraft-based Java console app where users can make custom potion, buy brewing supplies or villager trades, and generate receipts for the order

The program has a focus on using menus to guide the user through different options for each functionality.

 ## Features 💎
 
- Create customizable potions by:
  - Main effect
  - Size
  - Form (Consumable, Throwable, Lingering)
  - Enhancements
  - Additional Attributes
  - Visual Effect
  - Potion helpers
- Add base potions
- Purchase Tradable Items
- Generate Receipt file
- Minecraft villager themed UI
- Input Validation
